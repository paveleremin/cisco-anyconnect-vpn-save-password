# Cisco AnyConnect Secure Mobility Client VPN (UPDATED - WORKS WITH THE LATEST VERSION)

This simple script will save you the hassle of constantly typing your password.

## Instruction

1. Copy file Cisco.vbs to your computer
2. Edit it and replace YOUR_PASSWORD with your password whitin the two quotation mark.
3. If you need, edit the system drive letter (C:) to another.
